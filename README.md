ExpressRailLK is a scalable and user-centric online railway ticket booking platform designed for Sri Lanka. Developed using the MERN stack, the system streamlines railway operations including timetable management, station coordination, ticket booking, and fare management.

Passengers can conveniently search available trains, select travel routes, and reserve seats in multiple classes with integrated online payment support via Stripe. The platform also provides real-time updates, booking confirmations, and digital e-tickets.

The system is enhanced with third-party integrations such as Google Maps for route tracking and Twilio / Gmail for notification services. An admin dashboard enables efficient management of trains, schedules, users, and transactions.
